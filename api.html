What the API Does

Six Endpoints.
One Intelligence Layer.

Every endpoint is built on the same sport-science-validated methodology that powers Aria, Stadiora, and Aria XI. Not a generic wellness score — a sport-specific decision engine.

01
Availability Index
Synthesises training load, recovery, wellness, and contextual signals into a 0–100 availability score with a four-tier classification: Full Training, Modified, Recovery Only, or Unavailable. One number. One call. One decision.
POST /athlete/availability
02
Sprint Readiness Score
Multi-factor readiness assessment combining neuromuscular status, fatigue load, sleep quality, and training history. Returns a session-specific output — what type of session this athlete can perform today, at what intensity, and why.
POST /athlete/readiness
03
Injury Risk Signal
Early-warning detection from training load spikes, recovery gaps, HRV trends, and wellness patterns — flagged before the athlete recognises the signal themselves. Returns a risk tier, contributing factors, and a recommended intervention.
POST /athlete/injury-risk
04
Return-to-Play Protocol
Structured progression scoring for athlete rehabilitation. Tracks stage completion, load tolerance thresholds, and phase-gate readiness criteria. Returns a current stage classification and a clear go/no-go for progression — removing guesswork from one of sport's highest-risk decisions.
POST /athlete/return-to-play
05
Coach Attention Queue
Cross-athlete intelligence that generates a priority-ranked queue of athletes requiring immediate coach review. Synthesises readiness deltas, threshold breaches, and trend anomalies across an entire squad — so the coach's attention goes exactly where it's needed first.
POST /squad/attention-queue
06
Player Passport
Longitudinal intelligence profile per athlete. Historical readiness baselines, load tolerance curves, injury history context, and long-term availability trend — all queryable in a single response. Build features that understand the athlete over time, not just today.
GET /athlete/passport
How It Works

One call.
One decision.
Immediately actionable.

Send what you have. Receive a decision. Aria Intelligence handles the synthesis — no data science team required on your end.

  • Works with any combination of signals — you don't need all of them
  • Returns a classification, a recommendation, and a confidence score
  • Flags which signals drove the decision, so coaches understand the output
  • Explainable by design — no black-box outputs
