What it does

One engine behind the Aria apps

Stadiora Labs builds the Aria Intelligence engine and the apps that run on it. Run with Aria for track and field athletes and Aria for Coaches for the people who train them are both live today. Aria 12 is the soccer app in the same family.

Reads what an athlete already logs

Recovery, training load, physical signals and how an athlete says they feel, read together instead of sitting apart in four different places.

Returns one call for the day

The output is something an athlete or a coach can act on before the session starts, not another chart to interpret first.

Shows the signals behind it

Each call comes with what drove it, so it can be questioned rather than taken on faith by whoever has to act on it.

Today

The engine already ships to athletes

Every athlete on Run with Aria is using Aria Intelligence, they just reach it through the app rather than through a request. The intelligence screen is the engine's output. It is live on both stores now.

Status

Programmatic access is planned, not live

There is no public API today. No endpoints, no keys, no documentation and nothing to sign up for. We would rather say that plainly than publish a specification for something you cannot call.

What we are doing instead is talking to the teams, clubs and platforms that want the decision layer inside their own product. Those conversations decide what gets built first, so the earlier you tell us what you need the engine to answer, the more of it you shape.

Teams and clubs

Tell us how you settle availability today, who makes the call and what you are working from when you make it. Aria for Coaches is live, so there is already something to try while the interface is being designed.

Platforms and developers

Tell us what you would ask the engine and what you would do with the answer. That list is what the first version gets built from, and it is short enough right now that yours would count.
