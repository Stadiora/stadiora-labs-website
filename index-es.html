Acceso developer

Regla de naming: Stadiora Labs es la compañía. Aria es la app para atletas. Aria for Coaches es el producto para coaches e instituciones. Aria XII es la capa de fútbol. Aria Intelligence API es el motor compartido.

Flujo institucional

El login debe iniciar con institución, deporte y rol.

Una universidad, club o academia debería autenticarse una sola vez y luego enrutar a cada usuario al espacio correcto por deporte.

01
Institución

Resolver la escuela, club, academia u organización.

02
Deporte

Elegir Atletismo o Fútbol / Soccer.

03
Rol

Enrutar coaches, staff, admins y atletas.
